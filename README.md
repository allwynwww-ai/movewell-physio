# MoveWell Physiotherapy Website

Modern, mobile-first physiotherapy clinic website built with **Next.js 16**, **React 19**, and **Tailwind CSS v4**.

## Features

- Homepage with hero, services, about teaser, CTA
- Services page (6 treatment areas)
- About page (therapist bio + clinic photos)
- **Testimonials page** (patient reviews + rating summary)
- Book Appointment page (ready for real booking integration)
- Contact page
- Sticky header + responsive mobile menu
- Design system: Teal `#0D9488` + Coral CTA `#F97316` + Navy

## Pages

| Route            | Description                          |
|------------------|--------------------------------------|
| `/`              | Homepage                             |
| `/about`         | Therapist & philosophy               |
| `/services`      | Full list of services                |
| `/testimonials`  | Patient reviews & ratings            |
| `/book`          | Appointment request form             |
| `/contact`       | Contact details + map placeholder    |

## Getting Started

```bash
cd movewell-physio
npm install
npm run dev
```

Open http://localhost:3000
